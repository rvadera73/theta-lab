# Weekly Operating Rhythm

## Weekly Cadence

| Day | Time (ET) | Activity | Output |
|-----|-----------|----------|--------|
| Monday | Pre-market | **Top-5 Action Report** | Prioritized actions for the week |
| Monday | Pre-market | Earnings calendar scan | Blackout flags for next 2 weeks |
| Wednesday | After close | Mid-week flag check | Any urgent ITM / news events |
| Friday | After close | Week-close review | Realized P&L, open position status |
| Friday | After close | Next week DTE watch | Positions expiring in 7-21 days |

## Monthly Cadence (First Monday)

- Realized P&L vs annualized target (Account A: 20%, Account B: 12%)
- Tier reassessment: any Tier 3 names graduating or exiting universe?
- Macro thesis review: any sector view changes?
- Phase gate check (120-day plan milestone)

## 120-Day Phase Gates

| Gate | Date | Milestone | Pass Criteria |
|------|------|-----------|---------------|
| Phase 1 end | Day 30 | Mock mode complete | 20+ paper signals, logic validated |
| Phase 2 start | Day 31 | Alpha mode live | Account A, $100K cap |
| Phase 3 start | Day 61 | Scale mode | Full Account A capital |
| Phase 4 start | Day 91 | Retirement mode | Account B automation enabled |

## Top-5 Action Report Format

Generated every Monday. Skill reads current positions, open P&L, DTE, and regime to produce this.

```
THETA-LAB WEEKLY ACTION REPORT
Week of: [DATE]
Regime: [BEAR_SIDEWAYS / TRANSITIONING / BULL]
New entries allowed: [YES / NO]

TOP 5 ACTIONS THIS WEEK:

#1 [URGENT / MONITOR / REVIEW] — Ticker | Account | Action type
   Position: [description]
   Situation: [what's happening]
   Options: A) [option] B) [option] C) [option]
   Recommendation: [what to do and why]
   Deadline: [by when]

... (repeat for #2-5)

ALSO WATCHING:
- [positions near threshold but not yet actionable]

EARNINGS BLACKOUT NEXT 14 DAYS:
- [ticker] earnings [date] — [action: close / hold / note]

WEEK TARGET:
- Account A realized this week: $X (need $Y/week for 20% pace)
- Account B realized this week: $X (need $Y/week for 12% pace)
```
