================================================================================
MODULAR ARCHITECTURE: EASY TO EXTEND
================================================================================

Adding a new report type:
  1. Create new class (e.g., QuarterlyAnalysis)
  2. Inherit data from PerformanceEngine components
  3. Implement generate() method
  4. Add to PerformanceEngine.generate_all_reports()
  5. Done — no code duplication, clean separation of concerns

Adding a new risk check:
  1. Add method to RiskMonitor (e.g., check_vega_risk())
  2. Call from check_all()
  3. Return alert dict with type/category/action
  4. Done — alerts auto-integrate into all reports

Swapping data sources:
  1. Modify ClosedPLAnalyzer._load_transactions() to use new source
  2. Or create new subclass with custom logic
  3. Pass to PerformanceEngine.__init__()
  4. Reports auto-update — no changes needed
